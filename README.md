# Cognitive Blind Spot Self-Test

Self-reflection web app: "คนตาบอดทางความคิด" — 20-item Likert self-assessment across 5 cognitive-bias dimensions (Confirmation Bias, Identity-Protective Cognition, Actively Open-Minded Thinking, Bias Blind Spot, Intellectual Humility).

**Not a validated psychometric instrument.** Educational self-reflection tool inspired by:
- Dunning & Kruger (1999) — bias blind spot / overconfidence
- Kahan et al. (Yale, 2013–2017) — identity-protective cognition
- Stanovich & Toplak (2023) — Actively Open-Minded Thinking measurement
- Pennycook & Rand (2022) — accuracy prompts, Nature Communications
- Tetlock & Gardner — Superforecasting / Good Judgment Project
- Cusimano & Lombrozo (2023) — morally motivated reasoning, Cognition

All results stored in browser `localStorage` only — no backend, no data collection.
